Analysis of Linear System - Part 4 : ( Understanding the 2nd Order LDE )

May 19, 2026 · 4 min

ဒီနေ့တော့ LDE ရဲ့ အခြေခံသဘောတရားကို ဆက်လက်ဆွေးနွေးသွားပါမယ်။

System Modelling အကြောင်းမပြောခင် First Order နှင့် Second Order LDE တွေအကြောင်း အသေးစိပ် ထပ်ကြည့်ရအောင်ပါ။

ကျွန်တော်တို့သည် Electrical System ကို Analyze လုပ်တာဖြစ်ဖြစ်၊ Control System တစ်ခု (ဥပမာ- Drone) တစ်ခုကို design လုပ်တာဖြစ်ဖြစ်၊ Robot Arm တစ်ခုကို design လုပ်တာဖြစ်ဖြစ်၊ အာကာသယာဉ်ရဲ့ အပြင်ဘက်အကာကို design လုပ်ဖို့ အပူဒဏ်ခံနိုင်မှုကို တွက်ချက်တာပဲဖြစ်ဖြစ်၊ ဒုံးပျံ တစ်စင်းရဲ့ ‌လောင်စာကန်ကို design လုပ်ဖို့ လောင်စာ‌လောင်ကျွမ်းနှုန်းကို ခန့်မှန်းတွက်ချက်တာပဲဖြစ်ဖြစ် အလားတူ System များကို Modelling လုပ်တဲ့အခါ အများအားဖြင့် First Order နှင့် Second Order Linear Differential Equation တွေ ရကြလေ့ရှိပါတယ်။

ဒါကြောင့် အခုတော့ First Order နှင့် Second Order LDE အကြောင်းတွေကို အသေးစိပ် ဆွေးနွေးသွားပါမယ်။

ပထမ အနေနှင့် Standard Second Order LDE ကို ရေးပါမယ်။

$$A\frac{d^2w}{dt^2} + B\frac{dw}{dt} + Cw = e(t)$$

(အထက်ပါညီမျှခြင်းတွင် ဘယ်ဘက်ခြမ်းသည် Plant’s DNA ဖြစ်ပြီး၊ ညာဘက်ခြမ်း e(t) သည် Forcing function ဖြစ်သည်)

Plant DNA ဆိုတာက System ကိုအသေးစိပ်သိနိုင်တယ့် variable တွေ constant တွေပါတာကိုပြောတာပါ။ ထိုအ‌‌ကြောင်း အသေးစိတ်ကို System Modellingတွင်ရေးသားသွားပါ့မယ်။

  • \(w(t)\) သည် Position ဖြစ်သည်။ Constant \(C\) (spring stiffness) သည် \(w(t)\) ကို Oppose လုပ်သည်။

  • \(\frac{dw}{dt}\) \(\rightarrow\) Velocity term, constant \(B\) (friction) သည် velocity ကို Oppose လုပ်သည်။

  • \(\frac{d^2w}{dt^2}\) \(\rightarrow\) acceleration term, constant \(A\) (mass/inertia) သည် acceleration ကို Oppose လုပ်သည်။

အခုတော့ စာဖတ်သူတို့ ခေါင်းထဲမှာ ဘာလို့လဲဆိုတယ့် Why တွေနဲ့ ပြည့်နေမယ်ထင်ပါတယ်။

ဥပမာ

  • velocity တွေ acceleration တွေ friction တွေ က ဘယ်ကရောက်လာတာလဲ။

  • System တွေက တစ်ခုနဲ့ တစ်ခု မတူတာ ကို Second Order Linear Differential Equation တွေက အမြဲတမ်း ဒီလိုပဲလား။

Why တွေ အကုန်းလုံးကို အောက်မှာ အဖြေပေးထားပါတယ်။

  • ပထမဆုံး Newton’s Second Law of Motion ကိုကြည့်ရအောင်။
$$F = ma = m\frac{d^2x}{dt^2}$$
  • Hooke’s law အနေဖြင့်
$$F_{spring} = -k \cdot x$$
  • Fluid Dynamic အရ Linear Drag or Friction က
$$F_{friction} = -b \cdot v = -b\frac{dx}{dt}$$

ဥပမာ - mass တစ်ခုကို spring နှင့် တွဲလောင်းဆွဲထားပြီး ဆီကန်ထဲမှာ နှစ်ထားတယ်လို့ မြင်ယောင်ကြည့်ပါစို့။

1. ( Spring Force ) Hooke’s law အရ Spring ကို ပိုဆွဲလေ သူကလည်း ဆန့်ကျင်ဘက်ကို ပိုဆွဲလေ ဖြစ်လို့

$$F_{spring} = -k \cdot x$$

2. ( The friction Force ) Fluid dynamic က ပြောတာက မင်း ဆီထဲမှာ မြန်မြန်ရွေ့လေ ဆီက အရွေ့ကို ပို ဆန့်ကျင်လေ

$$F_{friction} = -b \cdot v$$

3. ( External Force ) ဥပမာ Block ကို မင်းလက်နှင့်တွန်းတာမျိုးပေါ့ \(F(t)\)

ထို System ကို Model လုပ်လိုက်ရင်

$$m\frac{d^2x}{dt^2} + b\frac{dx}{dt} + kx = F(t)$$

အထက်ပါ ညီမျှခြင်းကို Standard 2nd Order LDE

$$A\frac{d^2w}{dt^2} + B\frac{dw}{dt} + Cw = e(t)$$

ဖြင့် နှိုင်းယှဉ်ပါက-

  • \(A = m\) (mass)

  • \(B = b\) (friction)

  • \(C = k\) (spring stiffness)

အဲတော့ ပြန်ချုပ်ရရင်

  • Why constant \(A\) is mass → သင်္ချာအရကိုက mass က Newton’s law အရ acceleration နှင့် ကပ်ပြီး lock ဖြစ်နေတာ။

  • Why constant \(B\) is friction → သင်္ချာအရကိုက friction က fluid dynamics အရ velocity နှင့် lock ဖြစ်နေတာ။

  • Why constant \(C\) is spring → သင်္ချာအရကိုက spring stiffness က Hooke’s law အရ position နှင့် lock ဖြစ်နေတာ။

အဲတော့ Second Order Linear Differential Equation တွေ အကုန်လုံးက ဒီလို ပုံစံ လားဆိုရင်တော့၊ ဟုတ်ပါတယ်.. ဒီလိုပုံစံပါပဲ။ ဥပမာအနေနဲ့ ကျွန်တော်တွန်းလိုက်တာကြောင့် Block ကအောက်ကို သွားလိုက် Spring က ပြန်ဆွဲလို့ အပေါ်တက်လိုက် gravity က ဆွဲလို့ အောက်ပြန်ကျလိုက် နှင့် oscillate ဖြစ်ပြီး ဆီ ရဲ့ friction ကြောင့် နောက်ဆုံး stable ဖြစ်သွားတဲ့ system ပါ။ အခုဖော်ပြခဲ့တယ့် mass/spring/oil friction system တင်မဟုတ်ပဲ ၊ Universe တစ်ခုလုံးမှာ စွမ်းအင် storage နှစ်ခုကြား energy oscillate ဖြစ်ပြီး friction ကြောင့်နောက်ဆုံး စွမ်းအင်ကုန်သွားတယ့် မည်သည့် system ကိုမဆို 2nd Order Linear Differential Equation ဖြင့်ဖော်ပြနိုင်ပါတယ်။

နာမည် အကြီးဆုံး ဥပမာကို ပြရမယ် ဆိုရင်တော့ Electrical Circuit တစ်ခုဖြစ်တဲ့ RLC circuit ပါပဲ။

Capacitor နှင့် Inductor တို့ကြား စွမ်းအင် Oscillate ဖြစ်ပြီး Resistor ကြောင့် နောက်ဆုံး စွမ်းအင်ကုန်သွားတာ ပါပဲ။

ဒီ Circuit ကို Model လုပ်လိုက်ရင်

$$L\frac{d^2q}{dt^2} + R\frac{dq}{dt} + \frac{1}{C}q = V$$

\(L\) ——> Electrical mass

\(R\) ——> Electrical friction

\(\frac{1}{C}\) —–> Electrical Spring

  • ဒီမှာ Inductor သည် Wire Coil ဖြစ်ပြီး Magnetic Field ထုတ်ပါတယ်။ အဲ့ field ကနေ electricity ရဲ့ စီးဆင်းမှုအဟုန် (\(\frac{d^2q}{dt^2}\)) acceleration ကို oppose လုပ်တဲ့အတွက် \(L\) က Electrical mass ပါပဲ။

  • Resistor ကတော့ သိတဲ့အတိုင်းပါပဲ။ လျှပ်စစ်စီးဆင်းမှုနှုန်း (\(\frac{dq}{dt}\)) velocity ကို oppose လုပ်ပြီး အပူအနေဖြင့် Energy ကို ဖြုန်းတီးတဲ့အတွက် \(R\) က Electrical friction ပါပဲ။

  • Capacitor ကတော့ Spring နှင့်တူပါတယ်။ သူ့ထဲကို Electron များများဝင်လေ သူကလဲ Voltage များများ ပြန်တွန်းပြီး ဆန့်ကျင်ပါတယ်။ အဲတော့ \(\frac{1}{C}\) က Electrical spring ပါပဲ။

အရင် post တွေမှာ ဖော်ပြခဲ့တယ် Standard 2nd Order LDE

$$\frac{d^2w}{dt^2} + a_1\frac{dw}{dt} + a_0w = e(t)$$

နှင့် ယခု post မှာဖော်ပြခဲ့တယ့် Standard 2nd Order LDE

$$A\frac{d^2w}{dt^2} + B\frac{dw}{dt} + Cw = e(t)$$

က အတူတူပါပဲ (\(A\) ဖြင့်စားလိုက်ပါ)

$$\frac{d^2w}{dt^2} + \frac{B}{A}\frac{dw}{dt} + \frac{C}{A}w = \frac{1}{A}e(t)$$

  • \(a₁ = \frac{B}{A}\)

  • \(a₀ = \frac{C}{A}\)

ဒီနေ့ဖော်ပြခဲ့တာကတော့ Second Order LDE တွေ က ဘယ်လို ပုံစံလဲ ဆိုတာပါပဲ။

နောက် Post တွေမှာတော့ First Order LDE နှင့် Natural Response, Force response အကြောင်း / System Modelling အကြောင်း / Model Solution နှင့် System ကို guess လုပ်မယ် အကြောင်း / နှင့် System ကို Control လုပ်မယ် Control Theory တွေအကြောင်း / Linearization အကြောင်း / နောက်ဆုံးမှာတော့ လက်တွေ့ Project (1-DOF propeller pendulum) ကို အတူတူ design လုပ်ကြတာပေါ့။
