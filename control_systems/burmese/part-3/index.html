Analysis of Linear System : Part - 3

May 18, 2026 · 3 min

စနစ်တစ်ခု၏ အပြုအမူကို Linear Equation များဖြင့် ဖော်ပြနိုင်ပါက ၎င်းကို Linear System ဟု ခေါ်ဆိုနိုင်ပါသည်။ Linear Equation အမျိုးအစားများစွာရှိပါသည်။ Linear Algebraic equation၊ Linear difference equation သို့မဟုတ် Linear differential equation စသည်ဖြင့် အမျိုးမျိုးရှိကြပါသည်။ Ohm’s Law (\(V = IR\)) သည် Linear Algebraic Equation တစ်ခုဖြစ်ပါသည်။ အင်ဂျင်နီယာပြဿနာအများစုတွင် System များသည် Dynamic system (အလိုက်ပြောင်းစနစ်) များဖြစ်ကြပါသည်။

ဥပမာ - လူဦးရေတိုးပွားမှုနှုန်း၊ အပူချိန်၊ ရေငွေ့ပြန်နှုန်း၊ လျှပ်စစ်သံလိုက်စက်ကွင်းပြောင်းလဲမှုနှုန်း စသည့် Dynamic system များဖြစ်ကြပါသည်။ ၎င်းတို့ကို Differential Equation (အလိုက်ပြောင်းညီမျှခြင်း) များဖြင့် ဖော်ပြကြပါသည်။ ထို့ကြောင့် နောက်ပိုင်းတွင် Differential Equation များကိုသာ ဆက်လက်ဖော်ပြသွားပါမည်။

Standard Line Equation သည်

$$y = mx + b$$

ဖြစ်သကဲ့သို့

Standard Differential Equation သည်လည်း

$$\frac{d^2w}{dt^2} + a_1\frac{dw}{dt} + a_0w = e(t)$$

ဖြစ်ပါသည်။

ယခုရေးသားမည့် Linear Differential Equation အကြောင်းကို အနည်းငယ်ရှင်းလင်းဖော်ပြပါမည်။

Linear Differential Equation ဟုရေးရာတွင် အနည်းငယ်ရှည်လျားသောကြောင့် LDE ဟုအတိုကောက်ရေးသားပါမည်။

အထက်ပါ LDE တွင်

  • \(e(t)\) = Input (Excitation) Function

  • \(w(t)\) = Output (Response) function

  • \(t\) = Independent Variable

  • \(a₀, a₁\) = System Coefficient (constant သို့မဟုတ် \(t\) ၏ Function \(f(t)\) အဖြစ်ပါရှိနိုင်သည်)

\(a₀, a₁\) တို့သည် System အတွင်းရှိ Component များ၏ အရေအတွက်၊ တည်နေရာအချိုးအစားပေါ်မူတည်၍ ပြောင်းလဲနိုင်ပါသည်။

ထို့အပြင် ၎င်းသည် Second Order LDE ဖြစ်ပါသည်။ (\(\frac{d^2w}{dt^2}\) ပါသောကြောင့်)။ အကယ်၍ \(\frac{d^3w}{dt^3}\) ပါရှိပါက Third Order ဖြစ်ပါမည်။

အရင်ပိုစ်တွင် ဖော်ပြခဲ့သည့်အတိုင်း System သည် Linear ဖြစ်/မဖြစ် သိရှိရန်

၁) Superposition Principle \[e₁(t) + e₂(t) → w₁(t) + w₂(t)\]

၂) Homogeneity property \[n × e₁(t) → n × w₁(t)\]

တို့ကို လိုက်နာမှုရှိ/မရှိ စစ်ဆေးရပါမည်။

Physically

$$e_1(t) \rightarrow w_1(t)$$$$e_2(t) \rightarrow w_2(t)$$$$e_1(t) + e_2(t) \rightarrow w_1(t) + w_2(t)$$

Mathematically

$$\frac{d^2w_1}{dt^2} + a_1\frac{dw_1}{dt} + a_0w_1 = e_1 \quad \text{------Eq (1)}$$$$\frac{d^2w_2}{dt^2} + a_1\frac{dw_2}{dt} + a_0w_2 = e_2 \quad \text{------Eq (2)}$$

Eq (1) + Eq (2) ပြုလုပ်ပါက

$$\frac{d^2}{dt^2}(w_1+w_2) + a_1\frac{d}{dt}(w_1+w_2) + a_0(w_1+w_2) = e_1+e_2$$

ထို့ကြောင့် Superposition Principle ကို လိုက်နာပါသည်။

Homogeneity Property ရှိ/မရှိကိုလည်း အလွယ်တကူစစ်ဆေးနိုင်ပါသည်။ Homogeneity Property စစ်ဆေးရန်အတွက် Dependent နှင့် Independent Variable များအကြောင်း သိထားရန်လိုပါသည်။

ဥပမာ Velocity, (\(v(t) = \frac{ds}{dt}\))တွင်

  • Time (\(t\)) သည် မည်သည့်အရာကိုမှ မမှီခိုသောကြောင့် Independent Variable ဖြစ်ပါသည်။

  • \(v(t)\) သည် time (\(t\)) ကိုမှီခိုသော Function Of Time ဖြစ်သောကြောင့် Dependent Variable ဖြစ်ပါသည်။

  1. Dependent Variable တွင် ထပ်ကိန်းပါခြင်း (ဥပမာ - \(v(t)^²\))

  2. Dependent Variable နှင့် ၎င်း၏ Derivative များမြှောက်ထားခြင်း (ဥပမာ - \(v(t) × \frac{dv(t)}{dt}\))

  3. Dependent Variable ၏ Derivative တွင် ထပ်ကိန်းပါခြင်း (ဥပမာ - (\(\frac{dv(t)}{dt})^3\))

Differential Equation တစ်ခုတွင် အထက်ပါအခြေအနေများပါရှိပါက ၎င်းတွင် Homogeneity Property မရှိပါ။ ထို့ကြောင့် ၎င်းသည် Linear Differential Equation မဟုတ်ပါ။

အောက်ပါ Equation များကို Linear ဖြစ်/မဖြစ် စစ်ကြည့်ကြပါစို့

$$3\frac{d^2y}{dx^2} + y\frac{dy}{dx} + 2y = 5x^2$$

ဒုတိယ term (\(y\frac{dy}{dx}\)) တွင် Dependent Variable (\(y\)) နှင့် ၎င်း၏ Derivative မြှောက်ထားသောကြောင့် Linear Equation မဟုတ်ပါ။

$$\frac{du}{d\theta} + u + u^2 = \sin(3\theta)$$

တတိယ term (\(u^2\)) တွင် Dependent Variable \(u\) ကို ထပ်ကိန်းတင်ထားသောကြောင့် Linear Equation မဟုတ်ပါ။

$$t \left(\frac{d^2v}{dt^2}\right)^2 + 5\frac{dv}{dt} + t^2v = e^{-t}$$

ပထမ term

\[t(d²v/dt²)²\]

တွင် Dependent Variable ၏ Derivative ကိုထပ်ကိန်းတင်ထားသောကြောင့် Linear Equation မဟုတ်ပါ။

မှတ်ချက်

  • Independent Variable တွင် ထပ်ကိန်းပါခြင်း၊ Nonlinear Function ပါခြင်းတို့သည် Differential Equation ၏ Linear ဖြစ်မှုနှင့် သက်ဆိုင်မှုမရှိပါ။

လက်တွေ့ဥပမာ#

Resistor (\(R\)) နှင့် Capacitor (\(C\)) တို့ကို တန်းဆက် ဆက်သွယ်ထားသော လျှပ်စစ်ပတ်လမ်းတစ်ခုကို စဉ်းစားပါ။

ဤ Electrical System ကို Mathematically အားဖြင့်

$$\frac{dv(t)}{dt} + \frac{1}{RC}v(t) = \frac{1}{RC}V_s$$

ဟူသော Linear differential equation ဖြင့် ဖော်ပြနိုင်ပါသည်။

အထက်ပါ LDE တွင်

  • \(v(t)\) = Output Function (capacitor voltage)

  • \(Vs\) = Input Function (input signal)

  • \(\frac{1}{RC}\) = System Coefficient (Resistor နှင့် Capacitor အရေအတွက်၊ တည်နေရာအချိုးအစားပေါ်မူတည်၍ ပြောင်းလဲနိုင်သည်)

အကယ်၍ ထို Differential Equation ကို ဖြေရှင်းနိုင်ပါက ရရှိမည့် Solution သည် Output Function \(v(t)\) ဖြစ်ပါသည်။

\(v(t)\) ကိုသိရှိပါက System တစ်ခုလုံးကို ခန့်မှန်းနိုင်ပြီး လိုအပ်သလို ထိန်းချုပ်အသုံးပြုနိုင်ပါမည်။

ဥပမာ - Capacitor Voltage ကို 10 second အကြာတွင် 5 volt ရောက်ရှိစေပြီး 5 volt ရောက်ပါက အခြားပတ်လမ်းတစ်ခုကို activate လုပ်စေခြင်းကဲ့သို့သော ထိန်းချုပ်မှုများ ပြုလုပ်နိုင်ပါသည်။

ယခုပို့စ်တွင် Linear system ၏ ဂုဏ်သတ္တိများကို Mathematical ရှုထောင့်မှ တင်ပြပေးလိုက်ပါသည်။

LDE နှင့် စတင်ထိတွေ့သူများအနေဖြင့် ဖော်ပြပါ Differential Equation များကို နားလည်ရန် ခက်ခဲနေပါက စိတ်မပူပါနှင့်။

နောက်ပို့စ်များတွင် Linear Differential Equation များ၏ အခြေခံဂုဏ်သတ္တိများကို ဆက်လက်ဖော်ပြသွားမည်ဖြစ်ရာ ပိုမိုနားလည်လာမည်ဟု ယုံကြည်ပါသည်။

စိတ်ချမ်းသာပြီး ကိုယ်ကျန်းမာကြပါစေခင်ဗျာ။
