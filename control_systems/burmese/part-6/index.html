Analysis of Linear System - Part 6 : Linear Time Invariant (LTI) System

May 23, 2026 · 5 min

Linear Time Invariant System (LTI)#

Part-1 ကနေ Part-5 ထိမှာ ကျွန်တော် ဥပမာပေးခဲ့တယ် Electrical system တွေဖြစ်တဲ့ RC နှင့် RLC circuit တွေ၊ Physical system တွေ ဖြစ်တဲ့ mass-spring-damper (m, k, b) system တွေဟာ စာရွက်ပေါ်က equation တွေအတိုင်း အတိအကျ အလုပ်လုပ်တယ်လို့ ကျွန်တော်တို့ ယူဆခဲ့ကြပါတယ်။ အရှင်းဆုံး ပြောရရင် ကျွန်တော်တို့က သင်္ချာအရ ပြီးပြည့်စုံတဲ့ ကမ္ဘာလေးထဲမှာပဲ နေထိုင်ခဲ့ကြပါတယ်။

ဥပမာ - mass-spring-damper (m, k, b) system ကို ပြန်ကြည့်ရင်

အဲ့ system ဟာ သေသပ်လှပတဲ့ Differential Equation ကို ထုတ်ပေးခဲ့ပါတယ်။

$$m \frac{d^2x(t)}{dt^2} + b \frac{dx(t)}{dt} + k \cdot x(t) = F(t)$$

ဒါပေမယ့် ခါးသီးတဲ့ အမှန်တရားတစ်ခုကတော့ တကယ့်လက်တွေ့ ဘဝက ရှုပ်ထွေးပြီး ပြီးပြည့်စုံတယ် ဆိုတာ ခဲယဉ်းလှပါပြီ။ လက်တွေ့ကမ္ဘာကြီးဟာ ရှုပ်ထွေးပြီး ကမောက်ကမ နိုင်ပါတယ်။ တကယ့်လက်တွေ့မှာ Physical system တစ်ခုကို တည်ဆောက်တဲ့အခါ၊ အစိတ်အပိုင်းတွေဟာ ပူလာနိုင်တယ်၊ အရည်တွေရဲ့ စေးပျစ်မှု (viscosity) ပြောင်းသွားနိုင်တယ်။ ပြီးတော့ အစိတ်အပိုင်းတွေဟာ သူတို့ရဲ့ Physical limit ကို ရောက်သွားတတ်ပါတယ်။

အပေါ်မှာ ဖော်ပြခဲ့တဲ့ mechanical equation ထဲက friction coefficient (\(b\)) ကိုပဲ ကြည့်ရအောင်။ ကျွန်တော်တို့က သူ့ကို ပြောင်းလဲမှုမရှိတဲ့ constant အဖြစ် မှတ်ယူခဲ့ကြတယ်။ သို့သော် ကျွန်တော်တို့ ရဲ့ system က လေထဲမှာ အမြန် ရွေ့လျားနေမယ်ဆိုရင် ဘယ်လိုဖြစ်မလဲ။ တကယ့်လက်တွေ့မှာ လေထုပွတ်တိုက်အား (aerodynamic drag) ဟာ linear မဖြစ်ပါဘူး။ သူက (velocity) ရဲ့ နှစ်ထပ်ကိန်း နှင့် အချိုးကျပါတယ်။ ချက်ချင်းဆိုသလိုဘဲ (\(b\)) အပိုင်းက ပြောင်းလဲသွားပြီး ကျွန်တော်တို့ ရဲ့ equation ကလည်း Non linear equation အဖြစ် ပြောင်းလဲသွားပါတယ်။

$$m \frac{d^2x(t)}{dt^2} + b\left(\frac{dx(t)}{dt}\right)^2 + k \cdot x(t) = F(t)$$

Electrical system တွေ မှာ လဲ အလားတူပါပဲ။

ဥပမာ - RC circuit ကိုပြန်ကြည့်ရအောင်

$$RC \frac{dv_c(t)}{dt} + v_c(t) = V_s(t)$$

တကယ်လို့ ထို circuit ထဲကို heavy load တစ်ခု ဖြတ်စီးခိုင်းလိုက်ရင် ဘာဖြစ်သွားမလဲ? Resistor ပူလာမယ်။ ပူလာတာနှင့်အမျှ သူ့ရဲ့ (Resistance - \(R\)) ကလည်း တက်လာပါတယ်။ အဲ့ဒီအခါ \(R\) ဟာ constant မဟုတ်တော့ပဲ အပူချိန်အပေါ်မှာ မှီခိုပြီး ပြောင်းလဲနေမယ့် variable \(R(T)\) တစ်ခု ဖြစ်သွားပါတော့တယ်။ အပေါ်က constant \(R\) coefficient ပါတယ့် Equation လေးဟာ အောက်ကလို variable \(R(T)\) coefficient နှင့် equation ဖြစ်သွားပါတောတယ်။

$$R(T) \cdot C \cdot \frac{dv_c(t)}{dt} + v_c(t) = V_s(t)$$

ဒီလိုမျိုး တကယ့်လက်တွေ့ကမ္ဘာက ရှုပ်ထွေးမှုတွေကိုသာ ထည့်သွင်းစဥ်းစားလိုက်ရင် ရရှိမယ့် differential equation တွေဟာဆိုရင် Non linear ဖြစ်ရင်ဖြစ် သို့မဟုတ် system coefficient တွေဟာ constant မဟုတ်ပဲ variable တွေဖြစ်နေတတ်ပါတယ်။ ဥပမာ - အောက်ကလို Differential Equation လိုမျိုးဖြစ်သွားပါလိမ့်မယ်။

$$A(t)\frac{d^2x}{dt^2} + B\left(\frac{dx}{dt}\right)^2 + C(t)x = e(t)$$

System coefficient တွေဖြစ်တယ့် (A, B, C) တွေဟာ constant ဆိုရင် Time Invariant, မဟုတ်ပဲ Variable (A(t), C(t)) တွေဖြစ်နေရင် Time Variant ဖြစ်ပါတယ်။ (အောက်တွင် Time Invariant (TI) အကြောင်းကို ဆက်လက် ဆွေးနွေး သွားပါ့မယ်။)

ဒီလိုမျိုး ရှုပ်ထွေးတယ့် differential equation တွေကို စာရွက်ပေါ်မှာ တွက်ချက်ဖို့ ဖြေရှင်းဖို့ ဆိုတာ မဖြစ်နိုင်သလောက်ပါပဲ။ System ရဲ့ ရှုပ်ထွေးမှုပေါ်မူတည်ပြီး ရလဒ်ကို ခန့်မှန်းဖို့၊ တွက်ချက်ဖို့ Numerical method သုံးပြီး Processing Power မြင့်မားတဲ့ supercomputer တွေလိုလာပါမယ်။

ဒါကြောင့် Engineer တွေဟာ ဒီလိုမျိုး ရှုပ်ထွေး ခက်ခဲတဲ့ system တွေကို ရိုးရှင်းလွယ်ကူစွာ တွက်ချက်နိုင်ဖို့အတွက် linear ဖြစ်အောင်လုပ်၊ time invariant(constant coefficient) အဖြစ် ယူစ ခန့်မှန်း တွက်ချက်ကြပါတယ်။

!!!Teaser တကယ့် system က Time Invariant (constant coefficient ) မဖြစ်တာကို Time Invariant ဖြစ်တယ်လို့ ခန့်မှန်းပြီး Model လုပ်တော့ System ကဘယ်လို တိကျမှာလဲလို့ တွေးနေရင်တော့ မှန်ပါတယ်။ ဒီလို မတိကျတယ့် Mathematical Model ကိုသုံးပြီး system ကို ဘယ်လို Control လုပ်မလဲဆိုရင်တော့၊ Control System Theory အကြောင်း ‌‌‌ရောက်ရင် အသေးစိတ် ဆွေးနွေးသွားပါ့မယ်။

ဒါကြောင့် ကျွန်တော်တို့ အမြဲတမ်း Textbook တွေ၊ datasheet တွေမှာ ပါတဲ့ Linear Time Invariant (LTI) ဆိုတာ ဘာလဲ လေ့လာကြည့်ရအောင်။

1. Linear#

Linearity အကြောင်းကိုတော့ Part-2 နှင့် Part-3 မှာ အသေးစိတ် ဆွေးနွေးခဲ့ပြီး ဖြစ်ပါတယ်။ အကြမ်းဖျဉ်းပြောရရင် system တစ်ခု ရဲ့ Output ဟာ Input နှင့် exactly the same scale, proportionally ဖြစ်ရပါမယ်။ (Part-2 နှင့် Part-3 မှာ ဖတ်ကြည့်ပါ Linearity အကြောင်းကို သေချာရှင်းပြထားပါတယ်)

၂။ T I (Time invariant)#

နောက်တစ်ဆင့်ကတော့ LTI က T I (Time invariant) ပါ။

Time invariant ဆိုတာ system ရဲ့ physical properties က အချိန်နှင့် လိုက်ပြီး မပြောင်းလဲဘဲ constant ဖြစ်နေတာကို ပြောတာပါ။ ကောင်းကောင်း နားလည်ဖို့ Differential equation တစ်ခုကို ရေးပါမယ်။

$$A \frac{d^2x}{dt^2} + B \frac{dx}{dt} + C \cdot x = e(t)$$

(\(A, B, C\)) coefficient တွေ ဟာ constant ဖြစ်လို့ Time Invariant system ပါ။

$$A(t) \frac{d^2x}{dt^2} + B(t) \frac{dx}{dt} + C(t) \cdot x = e(t)$$

(\(A(t), B(t), C(t)\)) coefficient တွေဟာ constant မဟုတ်ပဲ အချိန်ရဲ့ function (or) အချိန်နှင့်လိုက်ပြီး ပြောင်းလဲ နေတာမို့အတွက် Time Variant System ဖြစ်ပါတယ်။

တကယ့်လက်တွေ့ ဥပမာများ#

RC circuit

$$RC \frac{dv_c(t)}{dt} + v_c(t) = V_s$$

(\(R, C, 1\)) coefficient တွေဟာ constant ဖြစ်လို့ Time Invariant system ပါ။ Resistor(ဥပမာ- 10 \(\Omega\)) နှင့် Capacitor(ဥပမာ - 2200 \(\mu F\)) တို့ရဲ့တန်ဖိုးတွေ ဟာ ဘယ်အချိန်ပဲဖြစ်ဖြစ် မပြောင်းလဲဘူး လို့ ခန့်မှန်း တယ့် Mathmetical Model ။

$$R(T) \cdot C \cdot \frac{dv_c(t)}{dt} + v_c(t) = V_s$$

\(R(T)\) coefficient ဟာ constant မဟုတ် ပဲ အပူချိန်ပေါ်လိုက်ပြီး ပြောင်းလဲတဲ့အတွက် Time Variant ပါ။ Resistor(\(R\)) ရဲ့တန်ဖိုးဟာ constant မဟုတ်ပဲ အပူချိန် ပေါ်မူတည်ပြီး ပြောင်းလဲနိုင် ဟု ခန့်မှန်း တယ့် Mathmetical Model ။

mass-spring-damper (m, k, b) system

$$m \frac{d^2x}{dt^2} + b \frac{dx}{dt} + k \cdot x = F(t)$$

System Coefficient တွေဖြစ်တယ့် (\(m, b, k\)) တွေဟာ မပြောင်းလဲတယ့် constants တန်ဖိုးတွေဖြစ်သောကြောင့် (Time Invariant System)

$$m(t) \frac{d^2x}{dt^2} + b \left(\frac{dx}{dt}\right)^2 + k \cdot x = F(t)$$

System Coefficient တစ်ခုဖြစ်တယ့် m(t) ဟာ အချိန်နှင့် လိုက်ပြီး ပြောင်းလဲတယ့် အတွက် Time Varient ၊ ဒါ့အပြင် (\(\frac{dx}{dt})^2\) ဖြစ်သောကြေင့် Non Linear လည်းဖြစ်ပါတယ်။ ထို့ကြောင့် (Non Linear Time Variant System) ဖြစ်ပါတယ်။ (ဥပမာ - အောက်တွင်ဖော်ပြထားသော Rocket example)

Intuitively စဉ်းစားကြည့်မည်ဆိုလျှင်…#

  • Time Invariant: RC circuit တစ်ခုကို charging လုပ်နေတယ်လို့ စဉ်းစားလိုက်ပါ။ တနင်္လာနေ့ မှာပဲ charge လုပ်လုပ် ၊ သောကြာနေ့မှာပဲ charge လုပ်လုပ် Output Curve ကတော့ အတူတူပဲ ဖြစ်ပါလိမ့်မယ်။ System Coefficient တွေဖြစ်တဲ့ (\(R\) နှင့် \(C\)) ဟာ အချိန်နှင့် မပြောင်းလဲတဲ့ constants တွေဖြစ်လို့ ဖြစ်ပါတယ်။

  • Time Variant: အာကာသကို လွှတ်တင်တဲ့ ဒုံးပျံတစ်ခု (Rocket) ကို စဉ်းစား ကြည့်ပါ။ Rocket Engine ဟာ တစ်စက္ကန့်ကို ဆီ ကီလိုပေါင်းများစွာ သုံးစွဲပါတယ်။ ဆိုလိုတာ က ဒုံးပျံ ရဲ့ အလေးချိန် mass (\(m\)) ဟာ constant မဟုတ်ပဲ ၊ အချိန်ပေါ် မူတည်ပြီး ပြောင်းလဲ နေမယ့် variable \(m(t)\) ဖြစ်ပါတယ်။ system coefficient \(m(t)\) က constant မဟုတ်လို့ Time variant ဖြစ်ပါတယ်။ (\(F = m(t)a\)) အရ Constant Trust (\(F\)) ကိုသာ သုံးမယ်ဆိုရင် လွတ်တင်ပြီး 100 second အကြာမှာဆိုရင် Thrust (\(F\)) သက်ရောက်မှုကြောင့် ဒုံးပျံဟာ ပေါ့သွားတဲ့အတွက် acceleration က စလွတ်တင်စကထက် အဆမတန် မြင့်တက်သွားပါလိမ့်မယ်။ ဒါ့အပြင် Air drag ကလည်း (\(\frac{dx}{dt})^2\) ဖြစ်လို့ Non Linear ဖြစ်ပါတယ်။

NOTE : System ဟာ linear ဖြစ်ပြီး ၊ coefficient တွေဟာလည်း constant တွေဖြစ်မယ်ဆိုရင် ထို system ဟာ Linear Time Invariant (LTI) system ဖြစ်ပါတယ်။

ဒါကြောင့် Engineer တွေဟာ system တွေကို၊ product တွေကို ဖန်တီးတဲ့အခါ ဒီလို LTI ဘောင်ထဲကပဲ ဖန်တီးကြပါတယ်။ သို့သော်လည်း တစ်ချို့ system တွေကို Design လုပ်ရာမှာ၊ ဥပမာ -

  • drone တွေ ကို design လုပ်တဲ့အခါ သုံးတဲ့ တွက်ချက်မှုတွေမှာ nonlinear air drag (\(\frac{dx}{dt})^2\) လို Term ပါတယ့် အတွက် ထိုကဲ့သို့သော Non Linear System တွေမှာ၊
  • inverted pendulum လို system တစ်ခု တည်ဆောက်ဖို့ တွက်ချက်ရာမှာ non-linear gravity (\(mg \sin(\theta)\)) လို Term ပါတယ့် အတွက် ထိုကဲ့သို့သော Non Linear System တွေမှာ ၊

System ကို လွယ်ကူစွာ တွက်ချက်နိုင်ရန် အတွက် အရင်ဆုံး Linear ဖြစ်အောင် Linerization Technique တွေသုံးပြီး အနီးဆပ်ဆုံး Linear Time Invarient(LTI) ဖြစ်အောင် လုပ်ကြပါတယ်။

ဘာကြောင့် system ကို LTI ဖြစ်အောင် လုပ်ရတာလဲ?#

System ရဲ့ Mathmatical Model ရပြီဆိုရင် ထို Model ရဲ့ Solution ကိုရှာရပါတယ်။ Differential Equation တွေကို တွက်ချက်ဖို့ အတွက် Classical Method တွေရှိပေမယ့် ခက်ခဲလှပါတယ်။ Classical Method တွေဟာ Normal Ordinary Linear Differential Equation တွေကိုတင်မက constant coefficient နှင့် မဟုတ်တယ့် Equation တွေ၊ အချို့သော Standard and Known Non Linear Equation (ဥပမာ - Bernoulli Equation) တွေကိုပါ တွက်ချက်နိုင်ပေမယ့် system ပေါ်မူတည်ပြီး အလွန်ခက်ခဲ နိုင်ပါတယ်။ ထို့ကြောင့် Engineer တွေဟာ Mathamatical Method တစ်ခုဖြစ်တယ့် Laplace Transform ကိုသုံးကြပါတယ်။ Laplace Transform Method ဟာ အလွန်လွယ်ကူပြီး Heavy Calculus Equation တွေကို Normal Algebric Equation တွေအဖြစ် ပြောင်းလဲပေးပြီး အလွန်လွယ်ကူစွာ Solution ကို တွက်ချက်နိုင်ပါတယ်။ သို့သော် Laplace Transfor Method ကိုသုံးဖို့တွက် Differential Equation (System Model) က Linear Time Invarient (LTI) ဖြစ်ဖို့လိုအပ်ပါတယ်။

Solution ရရင် System ကို နားလည်ပါပြီ။ သို့သော် Engineer ရဲ့အလုပ်က System ကိုထိန်းချုပ်ဖို့ပါ။ Model Solution အရ System ကို Microprocessor တွေ၊ Microcontroller တွေနှင့် ကိုယ်လိုချင်သလိုထိန်းချုပ်ဖို့အတွက် PID ကဲ့သို့သော Controller Algoritims တွေလိုပါတယ်။ ထို Controller တွေကိုသုံးဖို့ဆိုရင်လည်း System ဟာ Linear Time Invarient(LTI) System ဖြစ်ဖို့လိုပါတယ်။

ဒါကြောင့် System ကို ဖြစ်နိုင်သမျှ LTI ဖြစ်အောင်၊ အနည်းဆုံးတော့ LTI ဖြစ်ဖို့ သတ်မှတ်ထားတဲ့ အတိုင်းအတာ တစ်ခုမှာ LTI ဖြစ်ဖို့ လုပ်ရပါတယ်။

Model Solution, Classical Method, Laplace Transform, Control Theory တွေအကြောင်းကိုလည်း ဆက်လက်ဖော်ပြသွားမှာပါ။
