Analysis of Linear System - Part 5 : Understanding the 1st Oder LDE

May 20, 2026 · 3 min

မဖတ်မီ အကြံပြုချက် :!!! ဒီ Post ကို မဖတ်ခင် အရင် Post တွေကို အရင်ဖတ်ဖို့ အကြံပြုချင်ပါတယ်။ ဒီမှာ ဖော်ပြထားတဲ့ ပုံသေနည်း (Formula) တွေနဲ့ သင်္ချာ ညီမျှခြင်း (Equation) တွေကို အလွတ်ကျက်မှတ်ဖို့ မဟုတ်ဘဲ သဘောတရားကို သေချာနားလည်စေဖို့ပဲ ရည်ရွယ်ပါတယ်။ Newton’s Laws တွေ၊ Electrical Laws တွေလိုမျိုး ရူပဗေဒနဲ့ လျှပ်စစ်ဆိုင်ရာ နိယာမတွေကို မေ့နေခဲ့ရင်လည်း စိတ်မပူပါနဲ့၊ အင်တာနက်မှာဖြစ်ဖြစ် တခြား စာအုပ်တွေမှာဖြစ်ဖြစ် အလွယ်တကူ ပြန်ရှာကြည့်လို့ ရပါတယ်။

ပထမဆုံး First order LDE ရဲ့ Standard Form ကို ကြည့်ကပါစို့။

$$A \frac{dx}{dt} + Bx = F(t)$$

1st Order LDE ကို 2nd order LDE နဲ့ ယှဉ်ကြည့်ရင် 1st Oder LDE မှာ acceleration term ( \(ma\\) ) မပါ ပါဘူး။

ဆိုတော့ acceleration term မပါရင် ထို system သည် massless system ဖြစ်ပါတယ်။ Newton ပြောခဲ့သလို no mass, no inertia, no momentum ပါပဲ။ ဒါကြောင့် Massless system များဟာ momentum မရှိပါဘူး။

Momentum မရှိတဲ့အတွက်ကြောင့် system မှာ overshoot မရှိ၊ Oscillation မရှိ နိုင်ဘူးပေါ့။ Equation ကို ပြန်ကြည့်ရင် velocity term နှင့် position term ပါတာကို တွေ့ရမယ်။ velocity ကို ဆန့်ကျင်တာ friction နှင့် position ကို ဆန့်ကျင်တာ spring constant ဖြစ်ပါတယ်။ ဒါကြောင့် First-order system တွေကို Spring-Damper system လို့လည်း ခေါ်ကြတယ်။

Massless ဆိုတာ ဘာလဲ? (The Honey Analogy)#

ဗူးအပြည့် ထည့်ထားတဲ့ ပျားရည်ထဲမှာ စိတ်ပုတီးလုံးလေးကို လက်နဲ့ တွန်းနေတယ်လို့ တွေးကြည့်လိုက်ပါ။ လက်နဲ့ တွန်းထားတဲ့အချိန်မှာ လက်ရဲ့ velocity နှင့်ပဲ စိတ်ပုတီးလုံးလေးက ရွေ့ပါတယ်။ တွန်းတာရပ်သွားတာနဲ့ စိတ်ပုတီးလုံးလေးကလဲ ပျားရည်ရဲ့ viscous friction ကြောင့် ချက်ချင်း ရပ်သွားပါလိမ့်မယ်။

ပျားရည်၏ viscous friction သည် စိတ်ပုတီးလုံးလေး၏ mass ထက် ဆအဆပေါင်းများစွာ ပိုများတဲ့အတွက် စိတ်ပုတီးလုံးလေးမှာ mass မရှိဘူးလို့ အနီးစပ်ဆုံး ခန့်မှန်းပြီး မှတ်ယူလို့ရပါတယ်။

ဒါဆိုရင် ကျွန်တော်တို့ Spring-Damper တစ်ခုကို စဉ်းစားကြည့်ရအောင်။ mass တစ်ခုကို spring နှင့် ပျားရည်အပြည့်ရှိတဲ့ ကန်ထဲမှာ ထည့်ထားတယ် ဆိုပါစို့။

ပျားရည်၏ viscous friction က စောစောကပြောသလို mass ထက် ဆအဆပေါင်းများစွာ များတယ်ဆိုကြပါစို့။ ကျွန်တော်က F(t) အားနှင့် ကားလေးကို ဆွဲပြီး လွတ်လိုက်တယ် ဆိုပါစို့။ ကျွန်တော်ဆွဲသလောက် spring ကလည်း ဆန့်ကျင်ဘက်ကို ပြန်ဆွဲပါတယ်။ သို့သော် ပျားရည်၏ friction က အဆမတန် များတဲ့အတွက် overshoot နှင့် oscillation မဖြစ်ဘဲ နေရာတစ်ခုမှာ ငြိမ်သက်သွားပါလိမ့်မယ်။

Engineers Note: ထို့ကြောင့် Mechanical system တွေမှာ mass ရှိပေမယ့် friction ဟာ mass ထက် အဆမတန် ကြီးနေတဲ့အခါ Engineer တွေဟာ acceleration term ( \(m \frac{d^2x}{dt^2}\) ) ကို ဖြုတ်ပစ်လေ့ရှိပြီး model ကလည်း ပိုရိုးရှင်း၊ လွယ်ကူပြီး၊ ခန့်မှန်းရ အလွယ်ဆုံး first order LDE ဖြစ်သွားပါတယ်။

ဘယ်လို physical system တွေကို first order LDE နဲ့ ဖော်ပြနိုင်လဲ?#

  • Universe တစ်ခုလုံးက energy storage တစ်ခုပဲရှိပြီး Energy ကို အသွင်း၊ အထုတ် ကို Exponentially လုပ်တယ့် မည်သည့် system ကို မဆို first order LDE ဖြင့် ဖော်ပြနိုင်ပါတယ်။

ဥပမာ အနေဖြင့်

1. အပူ ထိန်းချုပ်မှု (Thermal system)#

90°C ရှိတယ့် အရမ်းပူနေတဲ့ ကော်ဖီတစ်ခွက်ကို 25°C ရှိတဲ့ အခန်းထဲမှာ ထားလိုက်တယ် ဆိုပါစို့။ coffee ရဲ့ အပူချိန်သည် တဖြည်းဖြည်း ကျလာပြီး နောက်ဆုံး 25°C မှာ ငြိမ်သွားပါလိမ့်မယ်။ overshoot ဖြစ်ပြီး 25°C အောက်ကို ရောက်သွားတာမျိုး၊ Oscillate ဖြစ်တာမျိုး မရှိဘဲ 25°C ကိုပဲ ငြိမ်ငြိမ်လေး exponentially ကျသွားပါလိမ့်မယ်။

2. Electrical System (RC circuit)#

RC circuit မှာ Capacitor ကို 20V နဲ့ အားသွင်းရင်၊ 20V အထိပဲ Exponentially ဖြည်းဖြည်းချင်း တက်သွားပါလိမ့်မယ်။ အားသွင်းရင်းနဲ့ 20V ကိုကျော်ပြီး overshoot ဖြစ်ပြီး 25V ကို ရောက်သွားတာတို့၊ oscillate ဖြစ်တာတို့မရှိဘဲ၊ အတိအကျ 20V မှာပဲ ငြိမ်သွားပါလိမ့်မယ်။ Discharge လည်း အလားတူပါပဲ။ ဒါကလည်း Exponentially ပြောင်းလဲပါတယ်။

အောက်တွင် RC charging Graph ကိုဖော်ပြထားပါတယ်။

RC circuit ကို model လုပ်လိုက်ရင်

$$RC \frac{dV_C}{dt} + V_C = F(t)$$

RC circuit မှာဆိုရင် 0V ကနေ 25V ထိ ရောက်အောင် ဘယ်လောက် အချိန်ယူမလဲ၊ ကော်ဖီ ဥပမာမှာဆိုရင် 90°C ကနေ 25°C ရောက်ဖို့ ဘယ်လောက် အချိန်ယူမလဲ ဆိုတာ သိဖို့ လိုအပ်ပါတယ်။

Time Constant of the System (\(\tau\))#

1st Order System တွေမှာ အရမ်းအရေးကြီးတဲ့ concept တစ်ခုကတော့ Time constant \((\tau\)) ပါပဲ။ သူကလည်း friction နှင့် spring constant ပေါ်မူတည်ပါတယ်။

အောက်တွင် Time constant formula ကိုဖော်ပြထားပါတယ်။

$$A \frac{dx}{dt} + Bx = F(t)$$$$\tau = \frac{A}{B}=\frac{b}{k}$$

  • Friction \(b\) များလေ \(\rightarrow\) system က နှေးနှေး response လုပ်လေ။

  • Spring stiffness \(k\) များလေ \(\rightarrow\) system က မြန်မြန် response လုပ်လေဗျာ။

နားလည်ဖို့ အရမ်း မလွယ်ဘူးလားဗျာ။

Mathematically အရကိုက Exponential function က အောက်ပါအတိုင်း ဖြစ်ပါတယ်။

Time Value (% of final value)
1\(\tau\) 63.2%
2\(\tau\) 86.5%
3\(\tau\) 95.0%
4\(\tau\) 98.2%
5\(\tau\) 99.3%

ထို့ကြောင့် Engineering မှာဆိုရင် system ဟာ \((5\tau\)) ရောက်ရင် stable ဖြစ်ပြီလို့ ပြောလို့ရပါတယ်။

ဥပမာ - RC circuit မှာဆိုရင်:

$$RC \frac{dV_C}{dt} + V_C = F(t)$$

  • Friction, \(b = RC\)

  • Spring constant, \(k = 1\)

$$\tau = \frac{b}{k} = \frac{RC}{1} \implies \tau = RC$$

ဒါကြောင့် \(5\tau = 5RC\) ဆိုရင် system stable ဖြစ်ပြီလို့ ပြောလို့ရပါတယ်။ \(R\) နှင့် \(C\) တန်ဖိုးကို ချိန်ညှိပြီး system ကို ဘယ်လောက် မြန်မြန် အလုပ်လုပ်စေချင်လဲဆိုတာကို သတ်မှတ်နိုင်ပါတယ်။
